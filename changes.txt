4. ADMIN LOGIN REDIRECT & ROLE AUDIT
--------------------------------------------------------------------------------
- Problem Audit: Checked why login via `/admin/login` was redirecting to `/admin/security-officer` instead of `/admin/hub`.
- Analysis:
  1. `AdminLogin.tsx` submits credentials to backend `/auth/login`.
  2. `AuthContext.tsx` `resolveLandingRoute` checks `roles.includes("admin")` first (returns `/admin/hub`).
  3. `roles.includes("privacy_officer")` is checked second (returns `/admin/security-officer`).
- Root Cause Identified: The backend database user for `admin@gmail.com` is seeded with `privacy_officer` / `security_officer` instead of `admin`. The frontend routing logic is 100% correct.
